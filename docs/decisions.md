# 重要决策与教训

只保留会影响后续实现的取舍；修复过程交Git，反例交tests，具体局次、耗时、usage、失败答卷和历史判卷归实验结果。

## 单一裁判与座位观察

规则代码统一裁定合法性和分数。策略只拿座位可见观察，用户端不裁判；裁判真值、未来墙与事后揭晓手牌不进入实时推断。旧录入接口与新裁判不混同。

## 共用大脑，解释与计算分离

数学事实、模型估计、策略假设和玩家语言分别标注。机器人与军师消费相同分析，不让解释偷偷改排序，也不把引用了正确事实当作策略正确证明。

LLM历史实验多次出现读牌自相矛盾、牌形误读、格式误拦与延迟。当前主线用可审计算法与回归；可选LLM代码仍有调用方，未做依赖核对不整包删除，不通过换提示词或重试刷局宣布能力提升。

## 动作合法与讲解可靠是两道门

非法动作不可执行，不能静默换成代码推荐。合法动作的讲解仍可能错误；问题讲解保留原文和校验结果，不作为可靠建议展示。过期模型记忆只可作历史参考，不能当当前局势事实。

## 牌理先核对再批评

689等复合搭子不能重复计算同一完成张；留三张花可能是在等四张暗杠，需比较占位、补牌次数和竞争。花多只说明条件赔付，不证明听牌；未声明叫牌不等于没有搭子。不同阶段的失败案例已由策略说明和回归用例承接。

## 实验不自动上线

自战不等于训练；接口合成探针不等于真人棋力；shadow-only对手基线不自动参与风险排序。真实失败、拒绝和未知usage分别记录，不把被护栏拦住算策略成功，也不修改原答卷掩盖失败。付费实验必须显式授权并有共享预算和失败保护，文档整理不触发模型调用。

## 文档只维护现行正文

规则增补合入rules，交互修正合入prototype/design，策略改造合入strategy，进度只进roadmap。Markdown是内容源；HTML自动生成。普通修复和完成任务不单开日期／版本文件；只有形成稳定独立职责才增加主文档。

历史原文已保留在整理前工作区快照；有实验意义的资料及哈希索引见 `artifacts/evaluations/document-migration.json` 与 `historical-evidence.json`。这些是证据，不是另一套现行设计。
