# 本地牌桌女声

38段牌名和动作音频由本机已安装的macOS Tingting女声合成，经ffmpeg处理为AAC/M4A。
仅作为本地试打素材；未复制腾讯、QQ欢乐麻将等游戏的录音或音乐。
重新生成：在项目目录运行`.venv/bin/python scripts/build_table_audio.py --force`。
不需要或自动下载安装网络TTS服务，也不调用LLM API。

背景旋律和短促音效由`audio.js`使用Web Audio在本地程序合成。
旋律是本项目编排的32拍五声音阶拨弦动机，不使用商业歌曲或外部采样。

声音默认开启，浏览器经过首次页面点击或按键后开始播放，无须专门点击声音按钮。
手动静音会持久保存，后续普通点击不重新启音。语音、音效和音乐可分别关闭或调音量。
语音随当前展示帧播放，新动作到来会停止过期语音，不补播历史动作；后台暂停声音。
对手摸牌不报牌名，暗杠只报“杠”，不使用隐藏牌种选择音频。
