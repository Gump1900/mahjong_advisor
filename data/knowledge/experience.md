# 太湖麻将：读牌、出牌与攻守经验

版本：2026-10-25，扩充草案。玩法口径沿用用户已确认规则；经验强弱待太湖牌谱校准，不证明现有军师已经掌握。新增项目推演不冒充外部已统计验证的结论。

用途：供LLM提出和修订策略假设；确定的牌形、向听、合法动作、过圈、资格花和赔付仍由代码提供。规则以[规则](../../docs/rules.md)为准，基础背景见[策略与信息边界](../../docs/strategy.md)。

接入状态：本文件尚未自动注入现有API。审核后应按当前局面选取相关条目，而非把全部资料、整书和所有案例无差别追加到提示词。下文的思考清单不改变运行时JSON字段或权限。

## 一、怎样使用经验，而不是把口诀变成错误规则

读牌不是复原唯一一副暗牌，而是在多种可能中调整关注顺序。必须同时保留主假设与反例，不能用一次舍牌给某种牌的存在概率清零。

- **硬排除**：由副本守恒、公开成组和本地规则决定。例如吃过牌不能再做七对；自己有一张某牌，对手不可能暗杠该牌四张。交给代码确认。
- **软线索**：某种舍牌顺序较符合某种做牌方向。只能说“暂时更留意”“这一解释较自然”；本文没有太湖牌谱校准，不能生成百分比。
- **行为假设**：对方倾向有效率地做牌、暂时进攻或保守。它可能错；新手、风格、手牌价值、主动防守都会改变舍牌选择。
- **决策**：即使某张可能危险，也不一定值得拆掉好形；即使某张相对不危险，也不等于值得为了它放弃现成收益。最终比较自己的机会与所有对手的威胁。

每次问自己：他为什么不要这张？它可能是孤张、复合形余张、对子拆出的牌，还是主动防守？哪一种解释最符合**当时**的信息？下一条什么证据会让我改判？

## 二、二十四条经验卡

### T01 早切2，不等于没有1、3；更不等于3安全

**类型：弱线索；用户例子与开源经验的太湖改编。**

观察：某家在较早阶段打出2万。

在“这张是从手中主动选择、倾向普通顺子牌效、没有明显防守或特殊做牌目标”的假设下，可以降低“仍留13万、正在等2万”这一解释的权重。不能改写成“他没有1万或3万”，也不能认定今后都不需要2万。

反例：1223万打掉一张2，仍有123完整顺子；13也可能是后来才摸成的。若摸切/手切未知，连“主动拆掉或拒绝这个搭子”的前提都不充分。**本次没有查到可用于太湖麻将的统计，不能声称早期1223这种例外概率很小。**

实战意义：开源防守实现把早切2与外侧1的相对风险修正联系起来，而不是把1、3一并视为安全。对方仍可能持有34万等2/5万，不能据此排除他有3万；若问打3万会不会放炮，则须另查12、24、45及对子等可能结构。“持有3”和“胡3”是不同问题。只把它当作同等方案间的弱线索，不凭这一张重手拆搭。[来源：开源防守实现的早期舍牌分支](https://github.com/MahjongRepository/tenhou-python-bot/blob/dev/project/game/ai/defence/main.py#L721)。

改判：对方随后吃入这一门、出现相邻手切或明显换形时，重新分析；不是把早先的排除永久保留。

### T02 手切、摸切、巡序影响线索强弱；不知道就不要编

**类型：观察质量。**

主动从原手牌选出的舍牌，能说明一次取舍；摸到后原样打出，通常更难据此推断其原有局部结构。没有来源标记时，只能写“来源未知”，不能根据机器人停顿时长、出牌动画或后来的全知牌谱猜成手切。

早期、中期、吃碰后和接近牌墙结束时的同一张牌，不能用同一条口诀解释。对方可能刚刚进张、拆搭、改目标或转守。开源分析器也专门区分手切与后续连续摸切，而非将整条牌河当成无时间次序的集合。[来源：对手舍牌序列处理](https://github.com/MahjongRepository/tenhou-python-bot/blob/dev/project/game/ai/defence/enemy_analyzer.py#L32)。

### T03 连续舍两门、保留一门：可以怀疑集中做牌，不能宣布清一色

**类型：假设，须结合公开成组。**

某家持续打饼、条，随后又吃碰万子，可提高对其万子方向的关注。但也可能只是万子已有普通面子、其他门孤张较多，不能认定清一色或已经听牌。

最有力的反证是公开成组与该牌型不兼容，应由代码直接排除；不能用“他看起来想做大牌”覆盖硬排除。南西北、花和暗杠的意义按太湖规则处理，不能套日麻役种。

应用：把“更留意这一门”与“具体猜哪张危险”分开。若不足以定位听口，保留宽泛方向，不随意报出几张危险牌。开源项目也把公开成组、巡序和手牌价值线索放到同一对手分析流程中；其中的日麻阈值不移植。[来源：EnemyAnalyzer](https://github.com/MahjongRepository/tenhou-python-bot/blob/dev/project/game/ai/defence/enemy_analyzer.py)。

### T04 吃碰与紧接着的弃牌要一起看，但“弃牌周边必危险”不成立

**类型：条件读牌。**

新吃碰告诉我们哪一部分已经完成；紧接着打出的牌则可能来自另一块，也可能只是刚完成这一块的余张。先分清两者，才能讨论剩余区域。

不能一见吃碰后打中张，就宣布其邻张是听口。原作者的读牌文章明确讨论了“余张来自哪里”这一前提，以及即使知道局部形状，也未必知道最终等哪边。[来源：ネマタ《読みの技術論》](https://note.com/nemata3939/n/n5ca8a2011691)。

自己构造的核对例：假设已公开两组，暗牌是455万、34饼、55条。吃入2饼组成234饼，再打5万，剩45万、55条，此时可讨论3/6万待牌。这个推导依赖整套假设；只看“吃饼打5万”无法知道对手就是这副牌。实际胡牌与资格由代码核对。

### T05 副露多，值得提高警惕；但副露数不是听牌证明

**类型：接近成牌的线索，不是确定状态。**

同样的副露数，早晚阶段与后续动作不同，意义也不同。三副露可能已听，也可能仍缺搭子、对子，或者有留花占位；四组也要核对剩余暗牌是否为花及本地胡牌条件。

现成天凤牌谱研究按巡序和副露次数分别统计向听，而不是用“碰两次就听牌”这样的硬规则。但它的样本是日麻，不能将其百分比直接用于太湖麻将。[来源：koba的原始统计文章](https://blog.kobalab.net/entry/20180203/1517667551)。

应用：副露推进用于提高观察优先级；牌型可行性、公开花分和是否互锁分别核对，不合并成一个“必听且很贵”的标签。

### T06 他没吃、没碰、没胡：信息有限，不等于没有相应牌

**类型：弱反证，特别容易误用。**

未发生声明可能因为没有牌，也可能因为保留门路、不愿拆形、互锁代价、过碰/过胡状态、等待自摸，或根本不是他的合法吃牌来源。除非知道当时确有合法机会，否则连“主动放弃”都不能断言。

对手之后有新摸牌或取得回合，旧线索更不能直接沿用。读牌作者也将未鸣牌作为有前提、可能被手变推翻的线索，而不是绝对排除。[来源：ネマタ文章末节](https://note.com/nemata3939/n/n5ca8a2011691)。

太湖补充：过胡限制所有接炮，过碰只限同牌种，私有状态未知时不能代别人宣布资格；这些都由规则引擎判定，不是经验口诀。

### T07 可见副本能堵住具体形状，但不能把“壁外”写成绝对安全

**类型：数学排除加剩余风险。**

若四张3万都已被自己与公开信息确定占用，则对手不能再持有含3万的暗搭子。因此若干涉及3万的顺子待法可排除；但对1万、2万的对子、刻子待牌等仍须另查，不能把排除某类顺子解释成排除所有胡法。

只见三张时，还有一张的位置未知，不能按四张全见处理。未知暗杠也不是“自己看到四张”。实现上可参考把强壁、弱壁和可能成牌形状分开的思路，具体排除交给本地代码。[来源：Kabe实现](https://github.com/MahjongRepository/tenhou-python-bot/blob/dev/project/game/ai/helpers/kabe.py)、[PossibleFormsAnalyzer](https://github.com/MahjongRepository/tenhou-python-bot/blob/dev/project/game/ai/helpers/possible_forms.py)。

### T08 日麻的筋与现物，不能直接当太湖的安全规则

**类型：禁止误迁移；来自本地规则的反例。**

太湖麻将没有“自己打过待牌，就永久不能接炮”的日麻振听规则。对方早打4饼，后来仍可能用56饼等4/7饼；只要当前本地资格允许，不能因为旧河里有4饼就认定7饼安全。

同样，“他自己打过这张”不是对他的绝对安全证明。开源日麻程序中明确包含基于现物、筋和役种的安全判断，这些部分不能整块搬过来。[来源：日麻防守入口](https://github.com/MahjongRepository/tenhou-python-bot/blob/dev/project/game/ai/defence/main.py#L27)、[Suji实现](https://github.com/MahjongRepository/tenhou-python-bot/blob/dev/project/game/ai/helpers/suji.py)。

保留的是“枚举哪些形状仍可能”的思路，而不是照抄日麻安全表、危险权重或立直阈值。

### T09 刚打过去的牌可以考虑跟，但必须逐家检查，尤其别忘弃牌者

**类型：本地规则下的时效线索。**

上家刚打3饼，我有孤张与34饼搭子，拆搭跟3饼可能是一种合理防守：相较于另一张，部分对手刚刚没有接这一张，可以作为临时线索。这并不自动优于清孤张，要说明防范谁、牺牲什么。

关键反例：上家不能接自己刚打出的牌，但太湖也没有永久禁止他接同牌的现物规则。若马上接我同牌且结构没变，往往还涉及他此前放弃自摸等额外行为假设，不能当作普通玩家的必然行为；状态变化后更须重评。其他家若已摸牌、补牌、吃碰取得回合或改变结构，“刚过去”的解释也可能失效。即便没有变化，也不能从公开未胡直接推断他们的私有状态。

正确表述：“对某家暂时较有依据”，不是“这张对三家都安全”。存在反例不意味着一律否定跟打，仍可正面比较它相对另一张牌的防守价值。

### T10 防下家，不只有防胡，还要考虑是否喂他吃牌

**类型：由座次与规则导出的策略取舍。**

只有下家能吃我的弃牌，三家都可能碰。因此同样不立即放炮的两张牌，也可能给下家不同的推进机会。

若下家公开成组及连续动作支持某门方向，可以在牌效接近时考虑不给他好接的材料；但不能只因牌河少某门，就认定他手里有某个搭子。也不能为了防他吃牌，忽视对家或上家的接炮风险。

计入向同一来源的口数与第三口互锁代价；不要把“刻意锁死别人”当策略目标。成功吃碰后的进展与代价由代码确认，未知暗牌决定的可吃性只能推测。

### T11 先区分“可能接炮”“接了会多贵”“可能自摸”

**类型：太湖攻守框架。**

花多会增加特定结算条件下的损失，但不证明已经听牌，也不指定哪张危险。已互锁者不能接炮，仍可能自摸；防守他和防守可接炮者不是同一个问题。

自己的可兑现机会很好时，允许承担有依据的风险；自己远、对手推进与潜在损失都值得警惕时，允许拆搭退让。不能将“机会多”“花多”“猜得像”随意相加成伪造期望收益。

每张候选分别看三家，不要把对一家相对妥当的牌称作全桌安全。牌型、底分、互锁倍数只取代码结果。

同张弃牌还可能一炮多响；不能只取潜在损失最高的一家，当作这张牌的全部条件赔付。逐赢家结算与合计由代码处理，是否会多人同时胡仍是不确定判断。

### T12 留花、等四张和保留搭子：经验必须对照具体机会成本

**类型：用户经验与本地规则改编，不是外部资料证实的最优策略。**

689饼切9仍保留68等7，不能因为9贴着8就批评其丢了7饼进张。先核对整手，再讨论其他完成方式、对子或风险；不固定写成永远切9。

手中三张东可能是等第四张暗杠，不是无目的留牌。比较该计划的成组价值、补牌次数与现在可换出的机会，不能只比潜在花分；也不能说每过一圈又少摸三张。

单留一花择时与等四张不是同一计划。若现在换已有直接杠开的条件机会，暂留必须解释以后想多争取什么。仅说“留着搏杠开”不够，因为现在换也可能杠开。条件结果不是命中概率，是否值得等仍由局势与模型判断。

### T13 牌效接近时，留更容易连接的孤张；风险明显时可以反过来

**类型：局部组合推演，不是整手进张排名。**

若两张都是孤张，整手当前向听、未见改善张和条件价值接近，可优先比较它们以后的连接空间。例如孤1万与孤4万：前者可与2/3万组成局部顺子搭子，后者可与2/3/5/6万组成；二者也都可能重成对子。

这说明4万通常有更多局部发展方向，不说明整手改善张必然更多，也不能把这些方向重复相加为胜率。若4万未来明显难处理、自己准备转守，而1万对主要威胁者相对有依据地较妥当，可以付出连接机会换取防守余地。

改判：邻张已见尽、其他块已占满、自己需要对子，或对手在该门推进时，重新比较。不能永远“先打幺九、保留中张”。

### T14 好形要看实际可得张数，不只看“两面”这个名字

**类型：数学比较加攻守取舍。**

45万局部等3/6万，46万局部等5万。其他条件相近且未见情况正常时，前者有两种完成牌，是值得保留的良形；但若3/6万已见尽、5万仍有未见副本，不能继续仅因“两面”就认定45更好。

比较时依次核对：整手结构是否可同时采用该形状、两边实际未见数、未知暗杠能否影响目标、完成后收益，以及为保形要打出的牌对三家的风险。未见不是墙内活张，牌种多也不保证更容易摸到。

不要为了把坎张改成两面，忽略当前已经可以胡牌或可以合法接炮的机会。改良和立即兑现是两个方案，要显式比较。

### T15 复合形的价值是选择权，不是重复计算同一张进张

**类型：局部形状与实体副本核对。**

2468万有24等3、46等5、68等7等局部可能，但共享的4、6不能同时当作两份独立资产。补到5形成456后，余下的2、8如何安排，还要看整手。

3345万可看见33对子和345顺子，但只有两张3，不能同时把它们固定成一个33对子加一个345顺子。它的好处在于可以随进张改分解，不是已经多出一组。

实战倾向：整手缺发展余地时，尽量别轻易把复合形拆成互不相连的孤张；整手块数已足够、需要对子或防守时，则可能应固定其中一种分解，舍去冗余。先问“这次弃牌究竟失去什么选项”，不要只数局部标签。

### T16 南西北的对子，不只是“字牌难连”；也别把潜在资格当现成收益

**类型：本地资格花带来的边际价值。**

无资格花时，南西北对子若以后成刻，除了形成一组，还可能打开接炮通道。这种价值与单纯增加分数不同。已经有资格花时，再追另一组风刻的作用又不同，应重新比较速度与条件收益。

更倾向保留的条件：风对子不明显拖慢整手、目标副本仍可能取得、接炮机会对当前手有意义。更倾向放弃的条件：目标已见得很薄、可换成明显更快的完成路线、风牌的后续风险正在上升。

不能为了风刻想象的收益，一直占着无进展的位置。也不能只比较“无花自摸”和“一花自摸”的金额，就忽略能否接炮；最终资格与金额由代码给出。

### T17 七对是竞争路线，不是看到几个对子就宣布目标

**类型：本地牌型选择。**

没有公开成组、对子较多时，应把七对与普通胡并排比较；四张同牌按本地七对口径处理。已有吃碰杠的牌，则不能再用普通七对路线为保留对子找理由。

更倾向继续七对：整手普通组合并不顺畅、对子路线的结构距离和未见完成张有竞争力。更倾向转换：顺子/刻子路线明显接近兑现，或者现有对子和孤张的可得副本已很薄。

碰出去的代价不止“少一个对子”，还包括关闭某些门路；但也不能为了保留理论上的大牌，放弃明显更可兑现的机会。不要把“牌型分高”代替做成的机会。

### T18 吃碰必须比较后续弃牌与听口，不能只看多完成一组

**类型：完整分支推演；下面牌例已用本地结构计算核对。**

原暗牌：112233万、456饼、789条、南风。结构上听南风。别人打2万，可以碰；若碰2万后打南风，剩1133万、456饼、789条，加公开的222万，结构上改听1/3万，仍是零向听。

现在再加公开信息：河里已有两张1万和两张3万，南风尚未公开。原听南风尚有未见副本；碰后的1/3万各两张在自己手里、另两张已在河中，未见张为零。当前待响应的是2万，也不是可立即接的1/3万。此时不能把“仍是零向听、听两种”当作变好了。

实战操作：对每个吃/碰，同时看其合法后续弃牌、当前响应窗口、留花、过圈、口数和条件赔付。别把吃碰当独立按钮，再临时凑一张弃牌。相反，如果吃碰确实缩短结构距离、保留合理听口且代价可接受，主动推进也有价值，不因“要门清”一律放过。

### T19 看变化点，不把早期解释无限延长

**类型：时序推断与假设过期。**

重点标记：第一次明显拆搭、第一次吃碰、连续手切中断、留花换出、再次取得回合，以及一直保留的区域开始出牌。新动作可能意味着进张后整理，也可能意味着转守或改目标。

若有可靠的来源标记，副露后持续摸切可支持“暂时不愿改动原结构”的解释，但不直接证明听牌；若之后重新手切，旧的固定听口猜测更要复查。没有摸切标记时，不能自行补上这段故事。

连续两次打同牌也不等于两份独立证据：可能在拆对子，也可能重复摸到，或者策略已变。面对后期的新动作，先问早期那条线索是否仍适用，而不是持续堆高置信度。

### T20 猜危险牌时，先列可能形状，再找支持与反证

**类型：候选听口推理；不输出未经校准的概率。**

例如担心3万，不要只说“靠近他打过的牌”。先考虑对方可能是12等3、24等3、45等3/6，还是对子、刻子相关待法；再结合已见副本、公开成组与舍牌顺序，判断哪些仍可行、哪些解释更自然。

数学排除交给代码；行为线索只调整剩余解释的关注顺序。一个顺子待法被排除，不代表这张就安全；能列出许多可能形状，也不代表他确实已经听牌。

若线索只支持“这一门值得留意”，就停在牌门层级；若两种解释都合理，就保留两种。不为显得像高手而凑满几张具体危险牌。

### T21 对未知暗杠做情景检查，不凭“没出现”指定牌名

**类型：实体副本约束加不确定性分析。**

自己持1、3条只等2条，而2条完全未见、对手有未知暗杠时，应比较两种情景：2条仍可能流通，以及四张2条全被暗杠占去。后者会使这个单一牌种听口无法再取得，不等于后者已经很可能发生。

自己单吊2条则不同：手里已有一张2条，其他人不可能暗杠四张2条。这个排除也不表示目标容易摸到，更不能进一步排除对手持有一张、对子或暗刻。

实战倾向：两个方案在正常情景相近时，可以重视哪一个更不怕目标牌种被暗杠耗尽；若另一条听口本来很差，也不能仅因“排除了暗杠”就断言它更好。没有暗杠候选分布，不能将候选牌种机械平均成概率。

### T22 分清“我被锁”与“他被锁”，防守对象会改变

**类型：太湖互锁规则下的策略推演。**

我已与A互锁，表示我与A本局都不能接任何人的炮；不表示未参与锁定的B、C不能胡我的炮。自己只能自摸，不等于可以无顾忌地甩危险牌。

若主要担心的A已被锁，防他点炮不再是该局的有效理由；但A仍可能自摸，我仍需考虑付款与被他抢先结束。另一张牌如果会直接放给未锁者，不能因A受限就忽略它。

尚未触发第三口时，是否再吃碰要比较：进度变化、失去接炮通道、与直接互锁者结算的倍数，以及能否来得及兑现。不能只看潜在高倍而追三口，也不能只因可能互锁就禁止所有推进。

### T23 防守要有库存和退出计划，不是打一张“看起来安全”的牌就结束

**类型：多步风险管理的经验假设。**

自己牌慢、可用进攻机会弱，而对手的推进和条件损失都值得警惕时，可以考虑保留暂时较有依据的备用弃牌，避免下一次被迫从每张都有作用的牌里硬拆。代价是占用自己的发展空间，不能无限囤牌。

一张备用牌只对特定对手、特定时点较有依据；其摸打、吃碰或换形后要复查。手里两张同牌也不能预先宣布能连续安全打两圈。

进入防守后仍记录重新进攻的条件：自己摸到明显改善、合法胡牌出现、主要威胁者受互锁限制或原危险假设被新事实削弱。反过来，好牌在手也要说明继续推进愿意承担什么，而不是因已经投入很多就一直冲。

### T24 给留花制定退出条件，别把“以后再说”当计划

**类型：本地换花时机推演，尚无最优性证明。**

结构距离较远、多花占位且没有具体等四张计划时，值得优先比较换出部分或全部花、取得新牌的路线。靠近成牌时，保留一花择时可能有吸引力，但须正面比较当前换牌已经提供的条件机会。

若留同款花等四张，应预先说明什么情况放弃：第四张被公开排除、其他家推进明显、自己出现更可兑现路线，或占位已迫使反复拆掉有用结构。不是没凑齐就一直留到末局。

牌墙减少是时间信息，不自动意味着必须立即换，也不自动让留花更好；要问剩下多少合法行动机会、是否还可能通过补牌兑现。输赢后也不能用“后来没来牌”证明当时必错。

## 三、四种打法姿态及转换信号

这些是可供LLM选择的策略姿态，不是由向听数触发的硬编码档位；同一局可以多次切换。

| 姿态 | 更适合比较的条件 | 承担的代价 | 必须重新判断的信号 |
| --- | --- | --- | --- |
| 争先兑现 | 当前合法胡牌或实际成牌机会有竞争力，等待的额外收益依据弱 | 可能放弃改良、做大或更高结算 | 新的真实威胁、资格/互锁变化、明确更好的合法分支 |
| 保留变化 | 两条路线当前接近，后续结构、对子或换花选择不同 | 暂不兑现某些立即机会，可能让别人先胡 | 目标副本减少、对手推进、关键结构形成或消失 |
| 攻守兼顾 | 不值得完全弃攻，但某家风险已有具体线索 | 可能少一些进张或打点 | 自己改善、对手换形、原线索失效 |
| 主动退让 | 自己机会弱，继续推进需付出没有充分收益支撑的风险 | 降低自己先胡的机会，别人自摸仍可能付款 | 现成胡牌或显著改善出现、主要威胁的接炮条件改变 |

不能只写“本局保守”。应落实到“这次选哪项、针对谁、相较备选付出什么、下一次看什么”。

## 四、每次决策的内部检查单

这是思考顺序，不是新增API输出字段：

1. **代码事实**：所选动作后实际剩哪些牌？能否胡、能否接炮？当前代价是什么？不要重新心算覆盖代码。
2. **逐家观察**：写清是哪一家的哪个公开事件、什么时序；摸切/手切未知就标未知。
3. **主假设与反例**：至少保留一个能解释同一现象的其他形状或策略；仅凭一次舍牌不要锁定听口。
4. **影响范围**：该线索只作用于哪个对手、哪个区域、哪类胡法？哪些胡法仍未排除？
5. **具体对照**：为什么选它而非备选？增加或保住什么，牺牲什么？有无同指标但不同结构的情况？
6. **改判条件**：对手新成组、相邻牌出现、取得回合、花分/互锁变化后，是否需要撤销旧猜测？

多条来自同一次舍牌的推断，不是多份独立证据。看到的东西能同时支持几种解释时，维持低把握，不因“故事顺”就上调为高置信度。局末揭示只能用来评估，不能塞回当时的推理输入。

## 五、给审核和后续验证用的反例题

| 观察 | 可讨论的判断 | 必须保留的反例/边界 |
| --- | --- | --- |
| 早巡打2万 | 降低13夹2作为主要解释的权重 | 1223打2；后来摸成；未知是否手切；3万不能一并判安全 |
| 打过4饼 | 作为舍牌历史的一部分 | 太湖无永久振听，之后56仍可等4/7 |
| 四张3万已见 | 排除需要暗持3万的具体形状 | 对子、刻子待法另查；不是全类型安全 |
| 吃饼后打5万 | 分析已完成块与余张来源 | 不知道剩余形状，不能断言听3/6万 |
| 三副露且花多 | 提高观察和条件损失的关注 | 不证明听牌；互锁者仍不能接炮；留花可能占位 |
| 刚有人打3饼未被胡 | 可讨论对部分人的临时线索 | 弃牌者本人可能接我同牌；其他人状态可能已变 |
| 自己持有目标牌一张 | 排除别人暗杠这四张 | 不保证其余副本在墙，不保证好摸 |
| 牌河很少某门 | 提出集中该门的候选解释 | 普通成组或配牌分布也可解释，不能直接报清一色 |
| 零向听从单吊变双碰 | 对比实际未见张和资格 | 双碰两种牌都已见尽时，不能只凭牌种更多称变快 |
| 3345万有对子和顺子 | 保留不同分解的选择权 | 不能把同两张3同时用于33对子和345顺子 |
| 自己与A互锁 | 自己与A均不能接炮 | 未锁的B、C仍可胡我的弃牌 |
| 暂留花计划未实现 | 根据新信息重新评估 | 不能用后来输赢倒推当时选择，也不能无条件一直留 |

通过这些题不等于“猜中全部暗牌”。应分别评价事实正确、反例是否保留、比较是否有用，以及新事件后是否合理改判。听口是否猜中也不能单靠一局输赢评价。

## 原则提炼 → 模型机制映射

1. **搭子四类价值序**：两面搭 > 卡张(中心3-7) > 边坎搭 > 边搭（会飞的猪）
   → 模型现状：已隐含在进张种数/活张；缺"中心性"显式权重。
2. **卡张比较的不是当下进张，是优化改良能力**："二四筒 vs 二四条进张一模一样，但二四条旁边有 6789"（会飞的猪·拆搭练习）
   → 模型：**1-ply/2-ply 弹性**已捕捉大半；"周边连带价值"（邻近已成牌/好型支撑后续拆转）可作 2-ply 项。
3. **拆搭三步口诀**：先数搭子（五搭为纲，搭多必拆）→ 比有效进张+改良空间 → 打完回头验（雀坛宝鉴）
   → 模型：结构分分解已含①②；③"验牌"= 打后向听/进张不劣化检查，可作排序后置断言（测试用例方向）。
4. **三对必拆一对**：对子超标=拆牌信号（雀坛宝鉴/两对半课）
   → 模型：块数约束进结构分（对子数上限的弹性惩罚）。
5. **两对半保留灵活性、不早拆中张**："打掉3万有点早，摸来九条还要面临拆搭"（会飞的猪·两对半）
   → 模型：**期权价值** = 1-ply 弹性同款；"早拆中张丢后续选择权"是弹性项的经典案例，直接进测试。
6. **五搭架构纪律**：过度分解成六搭必再拆=白亏一手（雀神在人间）
   → 模型：块数上限惩罚；分解枚举时的"标准五搭"约束。
7. **副露改变搭子身份**："五六饼被碰了，七饼之后这就相当于愚型"（鼎峰宝宝）
   → 模型：残余活张（4−可见）已覆盖大半；弹性计算需感知"邻居被碰"的连带降级。
8. **好型/愚型分类决策**：一对带三搭四分类，先分类再取舍（鼎峰宝宝）
   → 模型：分类是我们排序的特征输入，不是替代；教学用分类教人，模型直接用连续分。

## 真人经验 ≠ 真理（用户指正，建模红线）

- **7899饼 打9饼完全正常**——"弃边张→无邻张"是人的过度推断。边张读牌必须做**分级证据**：弃9对"持78"仅轻微降权（冗余解释多：7899/79+孤9都弃9），弃5对"持4/6"降权重（中张冗余解释少）。降权强度=该手型下此弃牌的真实频率，**从牌谱学**，不从口诀学。
- "刻子带搭不能留"等绝对化口诀 → 一律按似然证据处理，不写成硬规则。
- 教学价值排序（两面>卡张>边坎>边搭）是均值经验；具体局面被副露/趋势修正后可反转——模型用连续分+局面项，不用固定序。
